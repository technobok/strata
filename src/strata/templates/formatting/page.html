Format codes
  • 0 a digit, # a digit only when needed, . the decimal point, , thousands: #,##0.00 → 1,234.50
  • % percent: 0.0% → 25.6%; "text" in quotes: 0.00" kg"
  • Sections positive;negative;zero: #,##0.00;(#,##0.00) → (5.00)
  • Dates: yyyy-mm-dd, d mmm yyyy → 5 Nov 2026, hh:mm:ss, h:mm AM/PM
  • Text: @ is the text: "Item "@

Link templates
  • {Column} the row's value, encoded; {+Column} as it is (a column holding an address)
  • https://…?item={Item} an address; /nav?item={Item} this site; r/<report id>.html?item={Item} another report
  • An empty value in the template: that cell has no link
